# ASG-Airlines-Data-Engineering

## Project Overview

This project demonstrates an end-to-end data engineering workflow for ASG Airlines.

The workflow includes data ingestion, data profiling, data cleaning, transformation, validation, PII protection, KPI generation, and Power BI visualization.

## Tools Used

- Python
- Pandas
- NumPy
- Jupyter Notebook
- Power BI
- Excel

## Workflow

Raw Excel Data
→ Data Ingestion
→ Data Quality Checks
→ Data Cleaning
→ Data Transformation
→ Validation
→ PII Protection
→ KPI Generation
→ Power BI Dashboard

## Datasets

The project contains cleaned and analysis-ready datasets for:

- Flights
- Bookings
- Passengers
- Payments

## Key Analysis

- Average Flight Duration
- Route-wise Traffic
- Flights by Airline
- Booking Status Distribution
- Payment Analysis

## Privacy

Sensitive passenger information such as Aadhaar ID, passport number, email, phone number, and emergency contact details were excluded from the datasets used for analysis.

## Dashboard

An interactive Power BI dashboard was created with KPI cards, charts, and slicers for airline, source, destination, and booking status.
